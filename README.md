# Vault Sneakers

E-commerce React de sneakers criado como projeto de portfólio, inspirado na estrutura de um e-commerce moderno, mas com tema e identidade visual próprios.

## Recursos
- React + Vite
- Styled Components
- Catálogo responsivo
- Filtros por categoria
- Seleção de tamanho
- Carrinho lateral
- Alteração de quantidade
- Remoção de itens
- Cálculo automático do total
- Checkout simulado

## Rodar o projeto
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Pode ser publicado no Vercel.
